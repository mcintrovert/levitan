# LEVITAN

**Локальный голосовой ввод текста для Windows. На русском. Без облака.**

Зажал `Ctrl+Shift` → сказал → отпустил. Текст появился там, где стоит курсор:
в браузере, в Word, в мессенджере, в Конфигураторе 1С.

Речь обрабатывается на вашем компьютере. После первой загрузки модели интернет
не нужен вообще — можно выдернуть кабель, программа продолжит работать.

---

## Возможности

- **Ввод в любое поле** — вставка через буфер обмена, никаких интеграций с приложениями
- **Полностью локально** — [faster-whisper](https://github.com/SYSTRAN/faster-whisper) на CPU, видеокарта не нужна
- **Знаки препинания** расставляются автоматически, нужный знак можно продиктовать голосом
- **Автоподбор модели** под процессор: на слабой машине ставится модель полегче
- **Режим кода 1С** — разворачивает конструкции языка из голоса, с автозакрытием блоков
- **Живёт в трее**, поднимается вместе с Windows

## Требования

- Windows 10 или 11 (x64)
- ~1 ГБ свободного места под модель
- Микрофон
- Интернет один раз, при первой загрузке модели

Видеокарта не требуется. Всё считается на процессоре.

## Установка

Скачайте архив из [релизов](../../releases), распакуйте в любую папку и запустите
`LEVITAN.exe`. Установка не нужна.

При первом запуске программа скачает языковую модель (400–1500 МБ в зависимости от
выбранной) — прогресс виден в подсказке трея. Дальше запускается за пару секунд
и работает офлайн.

### Значок в трее

| Цвет | Что происходит |
|---|---|
| Серый | Загружается модель |
| Зелёный | Готов, ждёт |
| Красный | Идёт запись |
| Оранжевый | Распознаёт |

## Настройки

Двойной клик по значку в трее или пункт «Настройки…».

| Параметр | Описание |
|---|---|
| Модель | `auto` (по процессору), `small`, `medium`, `turbo` |
| Горячие клавиши | `Ctrl+Shift`, `Ctrl+Alt`, правый `Ctrl`, `Ctrl+Space` |
| Пунктуация | умная (гибрид), голосом, авто |
| Точность распознавания | `beam_size`: меньше — быстрее, больше — точнее |
| Ядра процессора | `cpu_threads`, 0 — автоматически |
| Автозапуск | запускаться при входе в Windows |
| Режим кода 1С | вручную или автоматически в Конфигураторе |

Настройки лежат в `levitan.json` рядом с exe — можно править и вручную.

## Режим кода 1С

Разворачивает конструкции языка 1С из речи:

| Говорите | Получается |
|---|---|
| процедура обработка проведения экспорт | `Процедура ОбработкаПроведения() Экспорт … КонецПроцедуры` |
| для каждого строка из товары цикл | `Для Каждого Строка Из Товары Цикл … КонецЦикла;` |
| если значение заполнено тогда | `Если ЗначениеЗаполнено Тогда … КонецЕсли;` |
| выборка точка контрагент | `Выборка.Контрагент` |
| регистр накопления | `РегистрНакопления` |

Плюс символы голосом: «равно» → `=`, «точка с запятой» → `;`, «открыть скобку» → `(`.

Код за вас он не пишет — это ускорение набора, а не генерация.

## Приватность

- Звук и текст не покидают компьютер, распознавание идёт локально
- После первой загрузки модели программа не обращается в сеть
- Телеметрии нет
- **Распознанный текст не записывается в лог.** В `levitan.log` попадают только
  время работы и число символов. Полный текст можно включить флагом
  `"debug_log": true` — но это осознанное действие для отладки

Честные оговорки: программа использует глобальный перехват клавиатуры (нажатия
никуда не пишутся, но технически доступ есть) и буфер обмена при вставке текста.
Если нужен максимум контроля — запускайте из исходников, они здесь.

## Сборка из исходников

```bash
pip install -r requirements.txt
python levitan.py
```

Сборка в один exe:

```bash
python -m PyInstaller LEVITAN.spec --noconfirm
```

Готовый файл окажется в `dist/LEVITAN.exe`. Модель внутрь не кладётся —
догружается при первом запуске.

## Структура

```
levitan.py              — приложение: трей, горячие клавиши, вставка
src/whisper_recognizer  — движок распознавания (faster-whisper)
src/postprocess         — пунктуация и голосовые команды
src/settings_window     — окно настроек (Tkinter)
src/code_1c             — режим кода 1С
LEVITAN.spec            — сборка PyInstaller
index.html              — лендинг проекта (GitHub Pages)
```

## Чего нет

- Вывода в реальном времени — прототип был, но текст дёргался и переписывался
  на ходу, отказался в пользу предсказуемости
- Версии для macOS — только Windows
- Подписи издателя, поэтому Windows показывает стандартное предупреждение
  о неизвестном издателе при запуске
